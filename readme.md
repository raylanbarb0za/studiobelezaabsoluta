# Projeto de Site para Salão de Beleza

## Objetivo
Desenvolvido com o objetivo de praticar conceitos fundamentais de linguagens WEB, com suas estruturas, estilos e muito mais.

## Tecnologias Utilizadas

HTML5, CSS e JavaScript

## Funcionalidades do Projeto

Página inicial com apresentação do salão;
Seção sobre o estabelecimento;
Catálogo de serviços oferecidos;
Galeria de imagens;
Informações de endereço e horário de funcionamento;
Google Maps integrado;
Integração com Instagram;
Agendamento e contato direto pelo WhatsApp;
Botão flutuante do WhatsApp;
Navegação por seções;
Menu responsivo para dispositivos móveis;
Design personalizado e responsivo;
Favicon e identidade visual própria;
Meta tags básicas para SEO.

## Objetivo Final

Este projeto faz parte dos meus estudos em programação e foi desenvolvido para colocar em prática conceitos aprendidos durante minha formação em Sistemas de Informação.

## Como Executar

1. Clone este repositório:

git clone https://github.com/raylanbarb0za/studiobelezaabsoluta

2. Acesse a pasta do projeto:

cd seu-repositorio

3. Execute no seu navegador 

Abra o arquivo index.html diretamente no navegador
